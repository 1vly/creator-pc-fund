# Creator PC Fund

Create a simple, clean, and modern single-page website with a dark theme. Keep the design minimal, professional, and easy to read on both mobile and desktop. Use subtle animations and hover effects.

Main Message (top of the page)

Start with a clear, direct heading:

“Let’s get to the point.”

Underneath, write:

“I need a better PC so I can make better videos for YouTube and finally get monetized. Anyone who helps pool money toward this PC will receive money back over time — even before I get fully monetized.”

Main Product Section

Feature this PC as the primary goal:

HZG M500 Gaming PC – $809

Ryzen 5 5600

RX 6600 8GB

16GB RAM

1TB SSD

Windows 11

Wi-Fi 6

Include a big “View & Buy on Newegg” button that links to:

https://www.newegg.com/hzg-gaming-desktop-pcs-amd-radeon-graphics-amd-ryzen-5-5600-16gb-ddr4-1tb-nvme-ssd-m50/p/3D5-006P-00028

Add a short note: “This is the one I need most. It will let me record and stream cleanly so I can start earning and pay people back.”

Interactive PC Diagram

Below the main product, create a simple interactive PC diagram (front or side view of a gaming PC case).

When the user hovers over each major part (CPU, GPU, RAM, Storage, Motherboard, PSU, Case), show a clean floating stat card with:

Part name

Short performance description

Price range

A “Buy” button (even if it just scrolls or links to the main PC for now)

Keep the diagram clean and not too cluttered. Use soft glow or highlight effects on hover.

Cheaper Gift Options Section

Title: “Too expensive? Here are some cheaper gift options”

Show these items in clean cards:

Keyboard

Add a small note under the cheaper one: “It is cheaper, but not as easy on my eyes.”

Absolute Cheapest Options Section

Title: “Want to help with something smaller?”

Show two types of digital gift cards in clean cards:

Discord Nitro Gift Cards

Roblox Gift Cards

Make the lowest price start at $30.

Display a few price options like $30, $50, $100 in a simple layout.

Do not include real purchase links for the gift cards — just show them as contribution options.

Overall Style

Dark background (#0f1115 or similar)

Clean cards with soft borders

Subtle hover effects and smooth transitions

Mobile-friendly

No clutter, no excessive colors

Professional and calm tone throughout

Make the whole page feel straightforward, honest, and easy to understand.
